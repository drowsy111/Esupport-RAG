# SupportHub 数据库连接排查手册（模拟）
本资料为个人项目构造数据，不代表真实软件产品规范。
适用：SupportHub 2.4.1；Docker Compose；MySQL 8.0。

## DEMO-DB-001：无法建立连接
先区分连接超时、认证失败和连接数耗尽，不要直接判断根因。

### 检查顺序
1. 确认应用连接的主机名、端口与部署说明一致。
2. 在应用所在网络内确认 MySQL 服务是否可达。
3. 检查 MySQL 是否健康启动，再确认应用账号权限。
4. 核对连接配置是否加载到应用进程。

### 验证
重新进行受控连接测试，记录时间和错误类型。
如果仍失败，补充完整版本、部署方式和脱敏后的第一条错误。
不得把数据库密码或真实客户配置粘贴到问答中。

## DEMO-DB-002：连接数耗尽
先观察活动连接、长事务、慢请求和连接释放情况。
估算连接预算时同时考虑 Worker 数量、每个 Worker 的连接池和其他客户端。
提高连接上限不是定位连接泄漏的替代方案。
