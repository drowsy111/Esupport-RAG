# SupportHub 2.4.1 部署说明（模拟）
本资料仅用于 RAG 测试，不是可执行的软件安装教程。

## 前置条件
使用 Docker Compose 部署时，需要确认服务网络、数据库版本和环境变量。
本模拟场景的数据库为 MySQL 8.0。
同一 Compose 网络中的服务使用服务名访问；容器内 localhost 指向该容器。

## 配置核对
检查 DB_HOST、DB_PORT、DB_NAME 和账号来源。
配置示例中的 CHANGE_ME 必须替换；真实密钥不保存到知识库。
代码和配置块中的缩进、连接符、下划线和版本点号都应保持原样。

## 健康检查
进程运行不代表业务依赖可用。
分别核对进程状态、数据库连接和一项只读业务请求。
